# Câmara Municipal de Itapeva/SP

Perfil oficial da **Câmara Municipal de Itapeva** no GitHub.

Este espaço é destinado ao armazenamento e versionamento de projetos internos do Poder Legislativo municipal. Os repositórios desta organização são **privados** e de uso restrito.

## Sobre a Câmara

A Câmara Municipal de Itapeva é o órgão do Poder Legislativo responsável pela elaboração das leis municipais, pela fiscalização contábil, financeira e orçamentária do Executivo, e pela representação dos cidadãos do município de Itapeva, no estado de São Paulo.

## Para o cidadão

Informações sobre sessões, vereadores, legislação, transparência e serviços estão no site oficial: [www.itapeva.sp.leg.br](https://www.itapeva.sp.leg.br). Este perfil no GitHub é voltado à gestão técnica dos projetos internos da Casa.

## Padrões de trabalho

- **Branches:** `main` para produção, `develop` para desenvolvimento e `feature/*` para novas funcionalidades
- **Commits:** mensagens descritivas informando o que foi alterado e o motivo da mudança
- **Issues:** demandas e correções são registradas como issues para acompanhamento
- **Pull Requests:** revisão antes do merge para garantir a qualidade do código

## Segurança

- Não incluir credenciais, tokens ou dados sensíveis nos repositórios
- Utilizar variáveis de ambiente ou gerenciadores de segredos para configurações sensíveis
- O acesso aos repositórios é concedido exclusivamente a pessoas autorizadas
